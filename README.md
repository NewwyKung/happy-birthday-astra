# Happy Birthday — Astra Experiment 🎂

**โปรเจกต์นี้สร้างด้วย AI 100% เพื่อทดสอบ Astra**

**Built 100% with AI to test Astra.**

เว็บเซอร์ไพรส์วันเกิดธีมครีมเหลือง–ส้ม สร้างจากคำสั่งในแชต โดยผู้ใช้เป็นผู้กำหนดโจทย์และทิศทาง ส่วนการออกแบบ เขียนโค้ด สร้างภาพ และแก้ไขงานดำเนินการด้วยเครื่องมือ AI

จุดประสงค์คือทดลองกระบวนการพัฒนาเว็บด้วย AI ผ่านแชต ตั้งแต่ไอเดียจนเป็นเว็บที่ใช้งานได้ คำว่า “AI 100%” หมายถึงงานออกแบบและการพัฒนาในโปรเจกต์นี้ ไม่ได้หมายความว่ามาตรฐานเว็บ เบราว์เซอร์ ฟอนต์ หรือเครื่องมือพื้นฐานถูกสร้างขึ้นใหม่ด้วย AI และไม่ใช่ผล benchmark อย่างเป็นทางการ

## Features

- ภาพเค้กวานิลลา 3D ที่สร้างด้วย AI พร้อมลูกโป่งและจานสีพีช
- แอนิเมชันลอยและการเอียงตามเมาส์
- ช่องพิมพ์คำอธิษฐานสูงสุด 280 ตัวอักษร
- ส่งคำอธิษฐานในหน้าเว็บ เป่าเทียน และโปรย confetti
- ข้อความอวยพรและปุ่มจุดเทียนเพื่อเล่นซ้ำ
- เสียง chime ผ่าน Web Audio API พร้อมปุ่มเปิด–ปิดเสียง
- Responsive layout และรองรับ `prefers-reduced-motion`
- Dialog และการควบคุม focus สำหรับการใช้งานด้วยคีย์บอร์ด

ภาพเค้กเป็น **ภาพเรนเดอร์ 3D แบบ raster ที่ขยับด้วย CSS** ไม่ใช่โมเดล WebGL ที่หมุนดูได้รอบทิศทาง

## Run locally

ไม่ต้องติดตั้ง npm dependencies หรือ build โปรเจกต์ ใช้ Python 3 เปิด static server จากโฟลเดอร์โปรเจกต์:

```bash
python -m http.server 8080 --directory dist
```

แล้วเปิด <http://localhost:8080>

ควรเปิดผ่าน HTTP server แทนการดับเบิลคลิก `index.html` เพราะ asset paths เริ่มจาก `/`

## Project structure

```text
dist/
  index.html                 # หน้าเว็บและแบบฟอร์มคำอธิษฐาน
  style.css                  # ธีม responsive และแอนิเมชัน
  app.js                     # คำอธิษฐาน เทียน confetti และเสียง
  assets/
    birthday-cake.png         # ภาพเค้กที่สร้างด้วย AI
    favicon.svg              # ไอคอนเว็บ
```

## Tech stack

Vanilla HTML, CSS, JavaScript, Canvas 2D และ Web Audio API ไม่มี frontend framework และไม่มี backend

ฟอนต์ Kanit และ Fraunces โหลดจาก Google Fonts หากเข้าถึงไม่ได้ เบราว์เซอร์จะใช้ฟอนต์สำรอง

## Privacy and limitations

- คำอธิษฐานอยู่ในหน่วยความจำของหน้าเว็บเท่านั้น ไม่มีฐานข้อมูล ไม่มีการบันทึกใน browser storage และไม่มีการส่งคำอธิษฐานให้บุคคลอื่นหรือบริการภายนอก
- รีเฟรชหน้าเว็บหรือกดเล่นซ้ำแล้วคำอธิษฐานเดิมจะหาย
- ไม่มีการขอใช้ไมโครโฟน การเป่าเทียนเป็นแอนิเมชันหลังส่งฟอร์ม
- เสียงเริ่มหลังผู้ใช้กดเปิดเสียง และขึ้นอยู่กับการรองรับของเบราว์เซอร์
- การโหลด Google Fonts เป็นคำขอไปยังบริการภายนอก แต่ไม่รวมเนื้อหาคำอธิษฐาน

## Validation

ตรวจ JavaScript syntax, ไฟล์อ้างอิง และตรรกะหลักด้วยการจำลอง DOM: เปิด/ปิดฟอร์ม ตรวจข้อความว่าง นับตัวอักษร ป้องกันส่งซ้ำ แสดงข้อความด้วย `textContent` เปลี่ยนสถานะเทียน เล่นซ้ำ และเส้นทาง reduced motion

ยังไม่ได้ตรวจหน้าตาและทดสอบการใช้งานครบทุกเบราว์เซอร์หรืออุปกรณ์จริง

## Deployment

นำเนื้อหาภายใน `dist/` ไปวางที่ document root ของ static hosting ได้ โดยไม่มี build step หากใช้ subpath เช่น GitHub Pages แบบ project site ต้องปรับ absolute asset paths ใน `index.html` ให้สัมพันธ์กับ subpath ก่อน

การเผยแพร่ repository นี้ไม่ได้เปิด GitHub Pages อัตโนมัติ
